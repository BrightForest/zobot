# Засмеялся-обосрался бот

Ищет на `/b/` треды по regex из Postgres и шлёт ссылки на картинки в личку подписчикам (`/disco` включает, `/pause` выключает).

## 3.0.0

Образ: `brightforest/zobot:3.0.0`. Go **1.27.4**, runtime `alpine:3.24` без toolchain. Бинарь по-прежнему `/app/zobotpic` — в compose меняется только тег.

- Очередь на 256 ссылок: опрос 2ch не ждёт рассылку. Между отправками по-прежнему 3 секунды, опрос `CHECK_RATE_SECONDS` (по умолчанию 60).
- Тред, пропавший из выдачи, вычищается вместе со своими URL.
- `Forbidden` пишется в колонку `blocked` и переживает рестарт. `/disco` снова включает доставку и снимает `blocked`.
- Битый regex пропускается, процесс из-за него не падает. TLS к 2ch проверяется.

На уже живой базе колонка создаётся при старте. Тот же SQL: [utils/migrate_blocked.sql](utils/migrate_blocked.sql).

## Сборка

```bash
docker build -t brightforest/zobot:3.0.0 .
```

Пуш и деплой вручную. В `utils/zobot2.yaml` тег уже `3.0.0`, секреты — плейсхолдеры.

## Команды

`/start`, `/help`, `/pause`, `/disco`.
